# Mock Service Worker (MSW) Setup

This project is configured to use Mock Service Worker (MSW) for API mocking during development and testing.

## Configuration

### Vite Configuration
The `vite.config.ts` has been updated to:
- Serve the `public` directory correctly for MSW files
- Define environment variables for MSW access
- Ensure proper module resolution

### TypeScript Configuration
The TypeScript configuration has been updated to include the `public` directory so MSW files can be imported.

### MSW Setup
- **Location**: `public/mockServiceWorker.js` (auto-generated by MSW)
- **Handlers**: `public/handlers.ts` (your custom API mocks)
- **Initialization**: `src/msw.ts` (development setup)

## Usage

### Development Mode
MSW is automatically enabled in development mode. When you run:
```bash
NODE_ENV=development pnpm run dev
```

The mock service worker will start and intercept API requests based on your handlers in `public/handlers.ts`.

### Testing
For testing, MSW is available through the test utilities in the `test/util/` directory.

### Adding New Mocks
1. Edit `public/handlers.ts` to add new API mocks
2. The changes will be automatically picked up in development mode
3. For testing, use the MSW browser utilities in `test/util/mswBrowser.ts`

## Troubleshooting

If MSW is not working:

1. **Check Environment**: Ensure `NODE_ENV=development` is set
2. **Check Service Worker**: Verify `public/mockServiceWorker.js` exists and is accessible
3. **Check Handlers**: Verify `public/handlers.ts` contains your mocks
4. **Check Browser Console**: Look for MSW-related errors
5. **Check Network Tab**: Verify API requests are being intercepted

### Common Issues

1. **Service Worker Registration Failed**:
   - Ensure the service worker file is being served with correct MIME type
   - Check that the service worker URL is correct

2. **Handlers Not Loading**:
   - Verify the handlers file is being served correctly
   - Check import paths in the MSW setup

3. **Tests Failing**:
   - Ensure NODE_ENV is set to development
   - Check that the test environment has access to MSW files
   - Verify the MSW browser utilities are working correctly
